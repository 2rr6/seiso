# M1 rule acceptance — 2026-09-28

M1 passed its rule acceptance gate with the project owner's
[protocol-rule exception](m1-gate-proposal.md). `KND001`, `KND002`, `LNK001`,
`SUP001`, and `SUP002` are stable and enabled by default. The six convention
rules remain preview. This record establishes acceptance of the local
implementation; it does not record a registry release.

Natural promotion required at least 100 labeled holdout diagnostics and
precision of at least 95% for each rule. Tuning results were reported
separately and did not contribute to promotion. The small convention-rule
samples do not estimate precision across other projects or document kinds.
This evaluation does not estimate recall or performance.

## Evidence and coverage

The run evaluated all 1,953 locked Markdown documents from 30 repositories,
including 662 holdout documents. Full commit-pinned Git inventories supplied
94,324 filesystem entries. Original document bytes were unchanged.

The [kind profiles](../../corpus/evaluation/kinds.json) were reviewed and
frozen before diagnostic generation. Effective resolution assigned a kind
to 219 documents; 1,734 remained unknown and ran only KND, LNK, and SUP.
These responsibility assignments are agent-reviewed evaluation assumptions,
not upstream declarations or human annotations. Their limited coverage is
one reason the convention rules remain preview.

All 3,909 diagnostics across tuning and holdout received a bound label.
Separate Python oracles checked declaration/configuration consistency and
link destinations against original bytes and complete Git paths. An agent
individually inspected a deterministic sample of 120 holdout cases for each
of KND001 and LNK001, all 13 convention diagnostics, and 45 additional link
reference cases. No human labeling is claimed.

LNK001's result means that a repository-relative physical target is missing.
Generated-site routes are included when the corresponding repository path
is absent; this is not evidence that a deployed website link is broken.
Symlinks, submodule contents, templates, and outside-workspace targets are
left undetermined. Five reference-key metadata anomalies had matching
original destinations and did not change link classifications.

## Protocol acceptance

The original corpus contained no actual kind declarations or seiso
suppression syntax. Natural precision for KND002, SUP001, and SUP002 is
therefore unavailable. Their accepted route used the reviewed protocol
matrix, deterministic results, exact source positions, executable examples,
and zero unwanted natural-corpus diagnostics. The
[protocol receipt](../../corpus/results/m1/protocol-acceptance.json) records
the passing conformance tests. Constructed tests were excluded from the
natural sample counts above.

## Preview findings

STL001 confused numeric table labels and contextual wording with volatile
state, and flagged an image-tag example explaining a naming convention.
PTR001 treated a metaphorical use of `see` as a direction to a repository.
The per-diagnostic labels preserve each judgment and its reason. Rule
behavior was not tuned on these holdout findings. A future promotion of
repaired convention rules requires fresh holdout evidence.

## Reproduce and inspect

Follow the [evaluation procedure](../../corpus/docs/evaluation.md).
The [frozen run](../../corpus/results/m1/natural-v1/run.json) identifies the
inputs and implementation. The [summary](../../corpus/results/m1/natural-v1/summary.json)
contains per-language/kind counts and annotation hashes; adjacent label
files retain individual judgments. The [promotion receipt](../../corpus/results/m1/promotion.json)
binds the enabled rule levels to the final implementation and verifies
unchanged diagnostics after promotion.
