# M0 parser acceptance — 2026-09-27

The pinned real-document corpus passed the M0 parser robustness and
determinism gate on Windows x64, using Rust 1.98.1 and Python 3.12.14.
The file selection was frozen before either full run.

| Measurement | Result |
| --- | ---: |
| Upstream repositories | 30 |
| Markdown documents | 1,953 |
| Original input bytes | 18,723,068 |
| Tuning / holdout repositories | 20 / 10 |
| English / Chinese / Japanese selection focuses | 20 / 5 / 5 repositories |
| Panics, process failures, timeouts | 0 |
| Parse/model failures, input mismatches | 0 |
| Forward / reversed report equality | Byte-identical |

Every document was parsed twice in CommonMark mode and twice in GFM mode,
then the full run was repeated in reverse file order: 15,624 successful
parse invocations. Source byte ranges were in bounds and on UTF-8 boundaries,
fragment mappings covered their decoded text, and model references were
consistent. Each repeated serialization matched, and the
two complete reports were identical.

The corpus lock SHA-256 is
`3904c6c396606d13a21de7296624bfff99054f60d872cb4da6a346ddb80487cb`.
The complete report SHA-256 is
`6c49b4c891f50587cb9f3379b665b091122eba149e066abf3c1246187076bfcb`.
The corpus directory retains the [acceptance receipt](../../corpus/results/m0/acceptance.json)
and [full per-file ledger](../../corpus/results/m0/report.json.gz). The ledger
includes the source and binary fingerprints used for this run.

The GFM model recorded 10 frontmatter content errors as data. These did not
cause parsing to fail and were not discarded. No lint rules or semantic
quality judgements were evaluated. Agent-tooling repositories were included,
but individual documents were not labelled by human versus agent authorship.

The existing mixed-language source-location regressions and all 70 Rust
tests also passed. Together with the published installation packages, this
satisfies the M0 exit criteria. M1's rule precision and stable promotion
criteria remain separate.

The [corpus procedure](../guides/corpus.md) reproduces the parser checks. Repository
membership and file selection are defined by the corpus lock, not by the
current contents of upstream branches.
