# KND002: Invalid document kind

## What it checks

Reports an unknown frontmatter kind or a frontmatter declaration of `generated`.

## Basis

Consistency. Kinds must use a supported value. Only configuration can mark
a document as generated and exempt its contents from checking.

## Why it matters

A misspelled kind cannot select the intended rules. Allowing a document to
declare itself generated would let its contents turn off their own checks.

## Example

```markdown
---
kind: guide
---

# Install

Run the installer.
```

## Instead

```markdown
---
kind: howto
---

# Install

Run the installer.
```

## Exceptions

Fix the declaration or move a generated assignment into configuration.
If an external system requires a different kind vocabulary, a temporary
file suppression must explain that constraint; kind-specific checks remain disabled.

## Inputs

YAML frontmatter. No filesystem lookup or repository index is required.

## Configuration

Select or ignore `KND002` through `[lint]`. Valid kinds and path mappings
follow the configuration contract.
