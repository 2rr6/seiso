# DUP003: Near-duplicate prose

## What it checks

Compares standalone paragraphs in the same language and configured domain.
Default candidates contain at least 80 letters or numbers and eight distinct
five-character shingles. Shingle-set Jaccard similarity must reach 0.9.

## Basis

Heuristic. Highly similar prose may maintain the same explanation twice.

## Why it matters

Repeated explanations can drift when readers and maintainers consult different pages.

## Example

In `guide.md`, when `reference.md` contains this same paragraph:

```markdown
---
kind: howto
---

The client reads the connection settings before opening a session. It validates the address and credentials, then applies the configured timeout to each request sent through that session.
```

## Instead

```markdown
---
kind: howto
---

See [connection behavior](reference.md#settings).
```

## Exceptions

Short text, lists, tables, block quotes, code blocks, and low-information
paragraphs are excluded. Similarity alone does not establish incorrectness;
required repeated notices or independent explanations can be suppressed with
a reason. Cross-language translations are outside the comparison domain.

## Inputs

Rendered prose, link text, and inline code are lowercased; whitespace is
collapsed. Link destinations do not contribute text. An inverted index over
rare-shingle prefixes selects candidates before exact similarity comparison. Ownership and
pairwise reporting follow `DUP001`.

## Configuration

Enable preview and select `DUP003`. `[lint.dup] min-paragraph-similarity`,
`min-paragraph-chars`, and `shingle-size` control the comparison. Files using
different shingle sizes are not compared. The rule has no automatic fix.
